# Everyday workflows

[Documentation](README.md) · [Русский](WORKFLOWS.ru.md)

The complete [user guide](USER_GUIDE.md) describes the current navigation. Use these routes for common tasks:

- **Start work:** Chats → New → project/provider → model → first message. On Windows, New is in the side rail. Continue the same chat for clarifications.
- **Review a result:** open Review from that chat, check the repository/branch and comparison mode, then scroll/collapse file diffs. Reading does not approve or merge.
- **Hand off between providers:** inspect shared project rules, the existing board card and relevant changelog, then verify current files. Changing provider does not reset the plan or authorize publication.

<a id="results"></a>
## Results

Results offers Images, Documents and Links, with source/assistant filtering. It scans available history separately from the chat viewport and reports progress or errors. Code and tools remain in the transcript and Review. See [results and images](USER_GUIDE.md#tool-activity-subagents-and-results).

<a id="activity"></a>
## Activity

Use the right-edge drawer for running, waiting, failed and completed chats. Read the final result to acknowledge completion; answer questions explicitly. [Notifications and saved state](USER_GUIDE.md#activity-notifications-and-usage)

<a id="tasks"></a>
## Product tasks

Current tasks are optional repository board notes or connected Miro content. Use [Boards](BOARDS.md). The old Jira Tasks page is retired from main navigation; existing Jira connection/host compatibility APIs are documented in [Reference](REFERENCE.md#jira).
