# Совместимость со старыми рабочими областями

[Документация](INDEX.ru.md) · [Текущие доски](USER_GUIDE.ru.md#boards)

Создание WorkSpace, приглашения и управление участниками больше не представлены отдельным разделом приложения. Текущие доски относятся к репозиториям; Miro подключается в настройках. Личные чаты относятся к подключённому ПК и провайдеру.

Старые приватные записи хоста и совместимые API сохранены, чтобы не терять существующие назначения и уведомления. Это не файлы доски репозитория; их нельзя переносить в Git. Старое уведомление может открыть исходную доску и заметку.

Для обычного подключения используйте актуальный QR в **Настройки → Подключение**. Создавать рабочую область для новой установки не требуется.
