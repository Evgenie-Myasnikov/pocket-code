# Документация Pocket Code

[Главная](README.ru.md) · [English](README.md)

Pocket Code — Android-приложение для работы с AI-инструментами на вашем Windows-ПК. На телефоне вы читаете чаты, отправляете инструкции, отвечаете на вопросы и проверяете изменения. Проекты и выполнение команд остаются на ПК. Это не удалённый рабочий стол и не точная копия всех возможностей Desktop-приложений.

Иллюстрации сделаны в настоящем интерфейсе на вымышленных данных. Внешний вид и подписи могут отличаться в зависимости от версии и выбранной темы.

Основные разделы — **Задачи**, **Чаты**, **Проект** и **Настройки**. Review, результаты и контекст субагентов открываются из соответствующего чата. Шторка активностей справа позволяет вернуться к выполняющейся работе из других разделов.

## Что потребуется

- Windows-ПК, Node.js 22+ и поддерживаемый AI-инструмент с выполненным входом. Текущий стандартный лаунчер проверяет наличие Claude или Codex; Copilot доступен как дополнительное рабочее пространство.
- Android 7+ и APK из релиза. Установку APK и обновлений подтверждает Android.
- Включённый ПК и работающий сервер. Для другой сети используется временный HTTPS-туннель; после отдельного перезапуска туннеля адрес может поменяться.
- Аккаунты AI-провайдеров с их собственными лимитами. Pocket Code не включает подписку на AI и не выдаёт права Jira или GitHub.
