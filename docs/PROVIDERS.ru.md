# Провайдеры и аккаунты

[Документация](INDEX.ru.md) · [English](PROVIDERS.md)

## Четыре разных подключения

| Подключение | Что разрешает | Где управляется |
| --- | --- | --- |
| QR Pocket Code | Доступ телефона к серверу на ПК | Страница QR и настройки подключения телефона |
| Аккаунт Claude, Codex или Copilot | Запросы к модели и инструменты провайдера | Нативные инструменты ПК; для Copilot есть кнопка запуска входа в приложении |
| Jira | Чтение задач и доступные действия процесса | Общее подключение ПК, доступное через страницу QR и настройки приложения |
| GitHub CLI | Публикация PR и доступ к репозиториям для функций сервера | `gh` на ПК |

Сканирование QR не выполняет вход во все сервисы. Вход в GitHub CLI сам по себе не подтверждает доступ к Copilot. Разрешение Atlassian для Claude не авторизует автоматически другой MCP-клиент.

## Claude

Войдите в Claude Code на ПК, затем выберите **Claude** в Pocket Code. Приложение использует Agent SDK для структурированных чатов и поддерживаемой локальной истории Code. Обычные облачные переписки Claude не импортируются.

В чате можно отправлять сообщения и вложения, раскрывать действия инструментов, отвечать на вопросы и запросы разрешений, останавливать выполнение. Уточнение можно отправить во время работы. Бюджет запроса в настройках относится к Claude; это не общий баланс аккаунта и не бюджет Codex/Copilot.

Подключение, использующее существующий Claude CLI, может расходовать лимит Claude. Отдельного пункта «Живой чат» или «Терминал» в навигации больше нет; старые серверные маршруты сохранены для прежних клиентов.

## Codex

Войдите в Codex на ПК и выберите **Codex**. Список моделей и вариантов effort приходит от установленного runtime. Effort запоминается отдельно для модели и применяется к следующему сообщению; доступные варианты зависят от модели и версии.

Desktop-чат можно читать, даже когда другой процесс владеет правом записи. Для продолжения с телефона завершите работу на ПК и освободите чат. Pocket Code не удаляет файлы блокировки и не закрывает Desktop самостоятельно. Отклонённое сообщение можно восстановить; оно не отправляется повторно без вашего действия.

В **Настройки → AI и рабочее пространство** доступны:

| Доступ | Поведение |
| --- | --- |
| Полный доступ | По умолчанию на телефоне: команды и операции с файлами без запросов подтверждения и песочницы проекта. Политики самого Codex сохраняются. |
| Запрашивать подтверждение | Песочница проекта и интерактивные подтверждения. |
| Подтверждать за меня | Автоматическая проверка разрешений самим Codex с песочницей проекта. |

Кнопка с вопросом раскрывает объяснение. Изменение применяется к последующей работе, а не к уже запущенному выполнению. Сценарии Jira для ревьюера и QA остаются в режиме чтения.

## GitHub Copilot

1. Выберите **Copilot** и откройте **Настройки → AI и рабочее пространство**.
2. Сервер проверит существующий вход Copilot.
3. Если нужно, нажмите **Подключить GitHub Copilot**. Завершите нативный вход GitHub в браузере на ПК.
4. Вернитесь в приложение и проверьте подключение. Модели загружаются из runtime.

Учётные данные остаются у инструмента на ПК. Разрешения на команды/файлы и поддерживаемые вопросы появляются в чате. Copilot не использует настройку полного доступа Codex. Уточнения передаются в очередь сессии Copilot: это не гарантирует немедленное прерывание текущего действия. Отображение лимитов подписки и контекст субагентов не имеют той же полноты поддержки, что у Claude/Codex.

Текущий стандартный лаунчер всё ещё проверяет наличие Claude или Codex. Установка только с Copilot пока не является полностью автоматическим сценарием запуска.

## Jira не зависит от AI задачи

На ПК выбрано **одно общее подключение Jira**. Откройте **Jira · Connect / Settings** на странице QR либо настройки Jira в приложении. Можно использовать существующее подключение Claude или прямой Atlassian MCP через Codex с отдельной авторизацией. Выбор Claude, Codex или Copilot для выполнения задачи не переключает аккаунт Jira.

Прямой MCP вызывает доступные инструменты Jira без запроса к модели. Путь через существующий Claude может использовать модель. Автоматического переключения аккаунтов нет. Atlassian может требовать одобрение администратора сайта, даже если в другом клиенте Jira уже работает. Перед сменой общего подключения завершите активную работу.

## Лимиты и параллельная работа

Экран лимитов показывает переданные провайдером окна использования и время сброса Claude/Codex. Кольцо возле поля ввода показывает минимальный применимый остаток. Если данных нет, показывается недоступность, а не нулевой расход. Набор окон зависит от аккаунта и runtime.

У одного провайдера одновременно могут работать до трёх задач Pocket Code в разных, не вложенных друг в друга папках. Сервер блокирует пересекающиеся проекты, в том числе между разными провайдерами. Разные Git-ветки в одной папке не обеспечивают изоляцию. Уже существующие worktree можно выбрать как отдельные папки; автоматического создания и слияния worktree пока нет. Остановка относится к конкретному чату. Ограничения сервиса провайдера могут быть строже лимита приложения.
