# Провайдеры и аккаунты

[Документация](INDEX.ru.md) · [English](PROVIDERS.md)

Подробный порядок входа, выбора моделей, прав и лимитов: [руководство](USER_GUIDE.ru.md#chats), [все способы ручного входа](PROVIDER-SIGN-IN.md).

| Провайдер | Модели и особенности |
| --- | --- |
| Claude Code | Каталог из Agent SDK, разрешённая версия псевдонима и ручной ID. Псевдонимы обновляются у провайдера; доступ проверяется аккаунтом. |
| Codex | Модели и effort из локального runtime; effort сохраняется по модели. Full access по умолчанию можно изменить. Чат Desktop может удерживать право записи. |
| GitHub Copilot | Каталог из SDK; нужен доступ к Copilot. Обнаружение аккаунта и права на модели — разные проверки. Поддержка лимитов/субагентов отличается. |

Вход и выход выполняются через провайдера на ПК. QR даёт доступ к хосту, но не авторизует AI, Miro или Jira. Устройство можно отозвать отдельно от аккаунта AI. Не передавайте токены через чат.

В текущих невыпущенных изменениях effort Claude доступен только для моделей, которые явно передали поддерживаемые уровни через SDK. Сервер проверяет выбранный уровень; настройки Claude и Codex сохраняются отдельно. Версия псевдонима больше не добавляет дубликат модели. Для ручного ID и недоступного каталога effort не угадывается.

Кольцо возле ввода показывает остаток лимитов аккаунта, а не заполнение контекста чата. Нажатие открывает отдельные окна и время сброса. Некорректные проценты, неудачное обновление и данные старше двух минут показываются как недоступные; они не превращаются в 0% или 100%. Проверка реального аккаунта зависит от входа и установленного runtime.

До трёх задач на провайдера могут работать в разных непересекающихся папках. На одну пересекающуюся область — один исполнитель, в том числе между провайдерами. Разные ветки в одной папке не дают изоляции.

Jira-соединение сохранено для совместимости; старой страницы Tasks в основной навигации нет. Miro подключается отдельно в настройках.
