# Pocket Code

**AI на вашем Windows-ПК, те же чаты на Android.**

Claude Code, Codex и GitHub Copilot: сообщения, изображения и файлы, вопросы агента, команды, дифы и результаты. Windows и телефон используют общие компоненты TypeScript/React. Работу выполняет ПК; подписка и права остаются у провайдера.

[Скачать](https://github.com/Evgenie-Myasnikov/pocket-code/releases/latest) · [Полное руководство](USER_GUIDE.ru.md) · [Документация](INDEX.ru.md) · [English](../README.md)

1. На ПК распакуйте исходники и запустите **Setup Pocket Code.cmd**. Подходящий Node.js определяется автоматически; при необходимости загружается проверенная локальная копия.
2. В настройках ПК проверьте вход AI и откройте **Подключение**.
3. Установите APK и отсканируйте QR в настройках подключения телефона. Откройте **Чаты → New**, выберите проект и отправьте сообщение.

QR — секрет. Не публикуйте его и не отправляйте в задачи. Закрытое окно Windows остаётся в трее; завершение — **трей → Выход**. Для свежих данных и работы AI ПК должен быть включён.

В приложении есть доски репозиториев, подключение Miro, Markdown-правила и changelog, темы, масштаб, сетка, уведомления и обновления через ПК. Доски необязательны. Сохранение доски не делает Git commit/push; Miro использует собственные права доступа.

**В текущих исходниках, ещё не выпущено:** Claude получает каталог моделей с версиями и ввод полного ID. Опубликованный 0.25.11 содержит прежний выбор псевдонимов. Подробности и ограничения — в руководстве.

Также в исходниках: [выполнение карточки в отдельной рабочей копии Git](TASK-PIPELINE.ru.md)
с чатом, проверками и одобрением; [доступ AI к Miro](MIRO-AI.md#кратко-по-русски)
с отдельными разрешениями; сохраняемые события для уведомлений Windows и Android.

Это независимый клиент, не официальный продукт провайдеров. Он не включает подписку, не импортирует все облачные чаты и не заменяет проверку результатов человеком.
