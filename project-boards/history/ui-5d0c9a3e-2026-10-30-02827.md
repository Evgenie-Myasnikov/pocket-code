# UI refinement chronology through 0.28.27

Archived from the existing UI card to restore its description below the schema limit. Historical pending statements are superseded by later validation and publication records.

Context
Unify Pocket Code UI around the matte/frosted composer; preserve compact layout, navigation, board interactions and readable themes. Add persistent chat alignment, one Thinking disclosure per turn with visible final answer/images, and optional free Supertonic 3 read-aloud with voice choice. Disable chat transcript selection while preserving copy/quote and draft editing.

Acceptance and implementation
Shared soft material across headers/actions, menus/dialogs, settings/forms, navigation, panels and board chrome; no luminous rims. Glass diffuses backdrop while foreground stays crisp. Chat alignment saves center/left/right. Quota is outside the frame, 6px horizontally from the visible ring and lifted 16px. Board uses pan/zoom-aligned line grid; resize and local card scrolling remain intact.
Thinking contains intermediate text, tools and reasoning; final answers and images remain visible. System speech selects text language and installed voice. Optional Supertonic 3 uses ten persistent speaker IDs, Preview/Stop, explicit fixed-model install with SHA-256 verification, authenticated host API and scoped Windows bridge. Weights stay outside Git/release packages; OpenRAIL-M notice retained. CPU inference runs in bounded native workers; Android receives WAV over its host connection. Stopping playback ignores late audio; a submitted chunk may finish on the host.

16 scoped browser scenarios and 10 server/unit checks passed, including real native WAV generation/cancellation, invalid model checksum, API authentication, settings preview/persistence, disabled transcript selection with copy/draft editing, glass pixels, alignment and board/chat interactions. Model installer/extraction probe, 13 native policy checks and Windows build passed. Synthetic captures inspected. Docs and board schema verification required before packaging.
