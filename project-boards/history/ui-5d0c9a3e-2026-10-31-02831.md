Acceptance and current implementation
Composer has a separate frosted backing layer that diffuses transcript pixels while text/input controls stay sharp. Access menu is portaled outside the form and retains outside-click, keyboard selection, focus return and resize/scroll positioning. Model/effort dropdowns use native base-select/picker styling where supported, with native color-scheme fallback.
Persistent independent switches control animated backdrops behind the conversation, transparent controls/composer and chat sidebar. Existing global enablement, style, tint, intensity and speed remain compatible; settings preview remains live and the renderer is removed when all relevant areas are off.
Regular desktop chat hides its duplicate top title when the chat sidebar is expanded, restores it when collapsed and keeps overflow actions; phone and board-chat navigation remain. Earlier delivered capabilities, final allowance placement around Send/Stop, visible assistant text/images above internal Thinking, streaming, fonts and local speech are preserved in linked history.
